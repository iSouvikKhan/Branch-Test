# Branch-Test

A practice repository used to learn Git branching. It contains personal notes on common Git branch commands and a minimal Java program used as sample content while experimenting with branches.

## Contents

| File | Description |
|------|-------------|
| `Branch_Notes.txt` | Notes on Git branching: creating, switching, merging, renaming and deleting branches (locally and on the remote), cloning a specific branch, and the difference between `git pull` and `git fetch`. |
| `Launch.java` | A minimal Java program that prints "Hello World !!" and the value of a variable. |
| `Launch.class` | Compiled bytecode of `Launch.java`. |

## Running the Java program

Requires a Java Development Kit (JDK) installed and on your `PATH`.

```bash
javac Launch.java
java Launch
```

Expected output:

```
Hello World !!
2 This is variable a
```
